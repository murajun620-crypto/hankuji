# NEXT Group

授業の発表班を抽選する、インストール不要の Web アプリです。

**アプリ:** https://murajun620-crypto.github.io/hankuji/

## できること

- 授業名と年度ごとにプロジェクトを作成
- 管理画面からプロジェクトを削除（確認後、設定と指名履歴も削除）
- 班の数（1〜52）と名称（英字、数字、第1班形式、自由入力）を設定
- 各班の指名上限（1〜100回）を設定
- 全班が1巡するまで同じ班を再指名しない設定を切り替え
- 日時付きの指名履歴を表示、CSVで保存
- 抽選時にルーレット演出を表示
- 「抽選ボード」で抽選画面だけを大きく表示（右上の「管理画面」または Esc キーで戻れます）
- 全プロジェクト・設定・指名履歴をファイルに保存し、別端末で開く

設定と履歴は利用しているブラウザにも自動保存されます。ブラウザのデータを消去すると履歴も消えるため、共有ファイルを定期的に保存してください。

## OneDrive で別端末と共有

1. 管理画面の左側にある「データの共有」から「保存」を押し、OneDrive に `NEXT-Group-data.txt` を保存します。
2. 別端末でアプリの「開く」を押し、OneDrive 上の同じファイルを選びます。読み込む前に、現在の端末のデータを置き換える確認が表示されます。
3. 抽選や設定を変更したら、再び「保存」して共有ファイルを更新します。自動同期は行いません。

iPad では OneDrive アプリにログインしておき、iPad の「ファイル」アプリで OneDrive を有効にしてください。「保存」は共有画面、「開く」はファイル選択画面を使います。OneDrive へのログインが必要な場合は端末側で行います。利用しているブラウザで保存先選択やファイル共有ができないときはダウンロードされるので、ダウンロードしたファイルを OneDrive に移してください。

## 動作確認

Node.js で `node --test` を実行できます。追加パッケージは不要です。

ローカルで画面を開く場合は `node scripts/dev-server.js` を実行し、`http://127.0.0.1:8765` にアクセスします。

## 公開

GitHub Pages の公開元を `main` ブランチの `/(root)` に設定すると、そのまま公開できます。
